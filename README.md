# EinkNote 개인정보 처리방침 (Privacy Policy)

최종 수정일: 2026년 9월 13일

EinkNote 서비스는 사용자의 개인정보를 소중히 여기며, 개인정보 보호 관련 법령 및 Google API 서비스 사용자 데이터 정책(Google API Services User Data Policy)을 준수합니다. 본 방침은 서비스가 Google OAuth를 통해 어떤 정보를 수집하고, 어떻게 사용 및 보호하는지 설명합니다.

---

## 1. 수집하는 개인정보 항목

EinkNote 서비스는 Google OAuth 인증을 통해 사용자의 명시적 동의 하에 최소한의 정보만을 수집합니다.

- **요청된 Google API 범위(Scopes):**
  - `[https://www.googleapis.com/auth/documents]`: 사용자 문서의 확인, 수정, 생성 및 삭제 권한
  - `[https://www.googleapis.com/auth/drive.file]`: 사용자의 특정 파일에 제한적 액세스 권한

---

## 2. 개인정보의 수집 및 이용 목적

수집된 정보는 다음 목적 이외의 용도로는 사용되지 않습니다.

- 사용자의 노트를 구글 Docs에 저장
- 서비스 핵심 기능 작성 : Eink 단말기에서 편리하게 텍스트를 작성한 후 구글 Docs에 저장하여 컴퓨터 상에서 자유롭게 노트 작성을 할 수 있다. 
- 서비스 공지사항 전달 및 고객 문의 대응

---

## 3. 개인정보의 보관 및 파기

- **보관 및 파기 :** 본 앱은 원칙적으로 개인정보 수집 및 이용을 하지 않습니다. 
- **연동 해제:** 사용자는 언제든지 로그아웃 혹은 앱 삭제로 [Google 계정 권한 관리 페이지](https://myaccount.google.com/permissions)에서 서비스의 접근 권한을 취소할 수 있습니다.
- 사용자가 남긴 정보와 파일 및 데이터베이스는 사용자의 단말기 내에만 저장되며 본인의 구글 클라우드 외에는 어디에도 저장되거나 배포되지 않습니다.

## 4. 제3자 제공 및 공유 금지

서비스는 원칙적으로 사용자의 사전 동의 없이 개인정보를 외부에 제공하거나 제3자와 공유하지 않습니다. 단, 법령의 규정에 의거하거나 수사 목적으로 법령에 정해진 절차와 방법에 따라 수사기관의 요구가 있는 경우는 예외로 합니다.

본 서비스는 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)과 **제한적 사용 요구사항(Limited Use requirements)**을 엄격히 준수합니다.
